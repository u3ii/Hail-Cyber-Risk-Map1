About the Project

Cyber Risk Map - Hail Municipality

Overview

The Cyber Risk Map is an interactive platform designed to visualize the dependencies between systems at Hail Municipality. It helps the cybersecurity department understand how a failure or breach in one system can affect others.

Problem

Municipalities operate multiple interconnected systems, but there is no clear tool that shows how these systems depend on each other. When an incident occurs, it's hard to quickly identify which systems are affected.

Solution

  • Asset Inventory - A complete list of systems with their status.
  • Dependency Map - A visual graph showing dependencies.
  • What-If Simulation - Test failures and see the impact.
  • Smart Reports - Automated risk assessment.
