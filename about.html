About the Project

Cyber Risk Map - Hail Municipality

Overview

An interactive platform to visualize the dependencies between systems at Hail Municipality, helping the cybersecurity team understand how a failure in one system can affect others.

Problem

Multiple interconnected systems, but no clear tool showing dependencies between them. When an incident occurs, it's hard to identify affected systems quickly.

Solution

  • Asset Inventory - Complete list of systems with status.
  • Dependency Map - Visual graph of dependencies.
  • Simulation - Test failures and see impact.
  • Reports - Automated risk assessment.
